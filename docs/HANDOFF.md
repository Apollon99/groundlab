### 1. Milestone completed

Hybrid RRF and hybrid + MiniLM reranking are available through the CLI on all three views.

### 2. Implementation summary

- RRF sums `1 / (60 + rank)` exactly over up to 100 real hits per parent and emits the top 100.
  It breaks exact ties by document ID. Short or empty BM25 lists contribute only their real hits.
- Both arms use the same hash-verified parent indexes. MiniLM reranks only the first 30
  candidates using finite logits on CUDA in FP32. Positions 31–100 retain their order. The
  pair encoder uses canonical text and document-only truncation at 512 tokens.
- MiniLM `model.safetensors` was downloaded at `233902d25c440f23af6f7d6e94d2946bac0bee0a`.
  Its 90,870,598 bytes matched the published LFS SHA-256
  `821d1aa69520101d6e0737f78a042ae25b19e5cb9160701909d10434f4aeb0ae`.
- Each fused run records its parent config hashes, index and model provenance, candidate digest,
  throughput, GPU memory, and timed single-query latencies. Evaluating rejects stale parent
  configs. The held-out guard binds the child and both parent configs to the freeze digest.
- The rank column controls evaluation. Rerank run-file scores are descending final rank scores.
  The hybrid run-file scores are rounded RRF scores.

  (exit 3) on any difference or when `input_sha256` is missing. `metrics.json` records
